# Simple-AI-Chatbot
A simple rule based AI based AI chatbot using python, NLTK and TKinter
🤖 Simple AI Chatbot

A simple rule-based AI chatbot developed using Python, NLTK, JSON, and Tkinter. It responds to user messages using predefined intents and responses.

📌 Project Overview

This project is a basic chatbot that understands simple user messages and provides predefined responses. It uses Natural Language Processing (NLP) techniques such as tokenization and lemmatization to process text.

🛠 Technologies Used

- Python
- NLTK
- JSON
- Tkinter

✨ Features

- Simple conversational interface
- Predefined intents and responses
- Text preprocessing
- Intent matching
- GUI-based interaction

📂 Project Files

- "chatbot.py" – Chatbot logic and text processing.
- "gui.py" – Graphical user interface.
- "intents.json" – Intents, patterns, and responses.

▶️ How to Run

1. Install Python.

2. Install NLTK:
   "pip install nltk"

3. Run the application:
   "python gui.py"

🎯 Project Objective
To develop a basic rule-based chatbot that answers common user questions and demonstrates the fundamentals of Natural Language Processing.
